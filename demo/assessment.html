Plan a hackathon from its messages

Upload the message pack - emails, WhatsApp notes, notices, in English, Urdu or Roman Urdu. The agent reads every message, builds the plan in code, checks it, and flags the risks. Nothing is pre-filled: the plan comes only from your file.

Drop the messages file here or click to choose it (.txt)

No key needed here - the demo runs on the site's own API key, held on the server and never shown to your browser. Your message text is sent through this site's proxy to the model API; see the privacy page.

Talk to the agent

Send updates in plain words - "printing ka bill 15,000 ho gaya" - or ask about the plan: "budget kitna bacha?", "risks batao". Updates go through the same checks as any message; questions are answered from the plan's own figures, with no model call.

Try to break it

Tricky messages, fired at your current plan. Watch the agent defend it.

Send an update message

One message at a time, exactly as it arrived. The agent reads it, recomputes only what it touches, and keeps the plan valid - or rejects it with the reason.
