Privacy

Short version: this site has no server and no accounts. Your file and your key stay in your browser, except for the one thing the tool exists to do - sending your message text to the model API you choose.

What leaves your browser

  • Your message text is sent to the API endpoint shown in Advanced settings (by default Groq, https://api.groq.com) so the model can read it. That provider's own privacy policy governs what it does with the text. Do not paste confidential material you would not send to that provider.
  • Your API key is sent only to that same endpoint, as the authorization header of the model calls. It is never sent to us - there is no "us" server - and it is not stored: it lives in the page's memory and disappears when you close the tab.

What never leaves your browser

  • The plan, the fact ledger, the chat and the trace are computed and displayed locally. They are not uploaded anywhere.
  • No cookies, no analytics, no tracking, no fingerprinting. This site sets nothing on your device.
  • The file you upload is read locally in the page. It is not transmitted as a file; only its text goes into the model calls described above.

The terminal version

The command-line version in the repository runs on your own machine. It makes the same model calls with your key and writes its outputs (plan, trace, state) to a local folder. Nothing else is transmitted.

Changes

If this policy changes, the new version will be published on this page with the change described in the repository history.
