Privacy

Short version: this site has no accounts and stores nothing. The one thing that leaves your browser is your message text, sent through this site's proxy to the model API so the agent can read it.

What leaves your browser

  • Your message text is sent through this site's proxy function to Groq (api.groq.com) so the model can read it. Groq's own privacy policy governs what it does with the text. Do not paste confidential material you would not send to that provider.
  • The demo API key belongs to the site owner and is held as an environment variable on the server. It is never sent to your browser, never shown on any page, and is used only to run the model calls this tool makes.

What never leaves your browser

  • The plan, the fact ledger, the chat and the trace are computed and displayed locally. They are not uploaded anywhere.
  • No cookies, no analytics, no tracking, no fingerprinting. The one thing stored on your device is your own session - the plan, the history and the chat - kept in your browser's local storage so the agent remembers earlier messages when a new one arrives. It never leaves your device, and the "Start a new plan" button erases it.
  • The file you upload is read locally in the page. It is not transmitted as a file; only its text goes into the model calls described above.

The terminal version

The command-line version in the repository runs on your own machine. It makes the same model calls with your own key (from your .env file) and writes its outputs (plan, trace, state) to a local folder. Nothing else is transmitted.

Changes

If this policy changes, the new version will be published on this page with the change described in the repository history.
